### 🌟 Featured Projects

#### 🩺 HIRA — Intelligent AI Health Platform

An AI-powered health assistance platform using agentic workflows and retrieval-based systems to provide responses grounded in user-provided health information.

**Engineering Highlights:**
- Developed LangGraph-based agent workflows with structured tool calling.
- Integrated PostgreSQL and ChromaDB for structured and semantic retrieval.
- Built backend services using FastAPI with Redis caching and background workers.
- Implemented LLM evaluation pipelines for response faithfulness, relevance, and safety.
- Provisioned AWS infrastructure using Terraform, including ECS Fargate, RDS, and ElastiCache.
- Performed load testing using Locust.
- Developed cross-platform applications using React Native and Swift.

**Technologies:**

`Python` `FastAPI` `LangGraph` `PostgreSQL` `Redis` `AWS` `Terraform` `Docker`

- Developed REST APIs enforcing business rules and data integrity.
- Integrated Gemini-powered AI features with organization-specific context.
- Built automated tests covering API behavior and application correctness.
- Developed web and mobile application interfaces.

**Technologies:**

`PostgreSQL` `REST APIs` `JWT` `RBAC` `React` `React Native` `Gemini API`
