### 🌟 Featured Projects

#### 🩺 HIRA — AI Health Coaching Platform
A LangGraph tool-calling agent (OpenAI-backed) that answers health questions grounded strictly in a user's own logged metrics and semantically-retrieved conversation history.
- Dual retrieval: structured Postgres tool calls + ChromaDB/Ollama vector search, served via FastAPI
- LLM-judged evaluation harness for faithfulness, relevancy, and diagnostic-refusal compliance
- Redis caching/rate-limiting with graceful degradation, RQ background workers, per-tool-call observability in MongoDB
- Full stack provisioned to AWS via Terraform (ECS Fargate, RDS, ElastiCache, ALB); load-tested with Locust
- Cross-platform clients shipped in React Native and Swift to an active user base

#### 🏢 Real Estate CRM
A multi-tenant SaaS CRM with org-scoped Postgres Row-Level Security, JWT auth via JWKS, RBAC, and audit logging on every mutation.
- Domain correctness enforced at the API layer: integer-paise money, forward-only deal-stage transitions, terminal-state guards
- Google Gemini AI proxy with org-scoped, context-window-managed prompting
- 32 API routes, 13 frontend screens (React + React Native/Expo), 220 passing tests

#### 🫁 DR-TB Detection System
An end-to-end deep learning pipeline for drug-resistant tuberculosis detection from chest X-rays.
- Data preprocessing, CNN model training, and evaluation in PyTorch
- Automated clinical report generation, deployed via Streamlit for real-world clinic use
- Presented at AIIMS Delhi 2025 (poster & oral)
